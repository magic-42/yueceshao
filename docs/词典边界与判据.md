# 词典边界与判据（rules/lexicon.py 的取舍规则）

> 本文是 `rules/lexicon.py` 的配套说明：**什么样的词可以进禁止用途词典、什么样的词必须拒收、收窄时按什么代价决定**。
> 起源：2026-11-06 两轮边界收窄（PR #43 撤回「造林」「兑付」、#44 撤回「种树」）暴露出"扩词很容易、误报很难发现"，
> 故把判据固定下来，避免下一轮再靠直觉裁词。

## 1 为什么要这个判据

规则引擎的匹配口径是**概念组共现**（描述侧词与条款侧词落在同一概念组即命中）。它不认识句法和否定，
所以一个词的"危险程度"完全取决于：**它会不会出现在一句完全合法的申报描述里**。

实测反例（都在合规表述上触发）：

| 词 | 合规表述示例 | 命中条款数 |
|---|---|---|
| 造林 | "在宜林荒山实施造林项目（非耕地、林业部门备案）" | **62** |
| 种树 | "在宜林地种树八十亩" | **62** |
| 兑付 | "按合同约定按期兑付工程款给施工单位" | **40** |
| 绿化／挖塘／苗木／草皮／景观 | "村庄绿化美化" / "非耕地挖塘蓄水" / "培育乡土苗木" … | **各 62** |

一条合规的荒山造林项目，报告②段会列出 62 条"命中提示"——这不是判定错误，但完全掩盖了真正的风险提示。

## 2 三判据（缺一即误判）

| 判据 | 含义 | 怎么算 |
|---|---|---|
| **① 误报面** | 该词单独出现在**合法申报表述**里会命中多少条条款 | 把词放进一句合规描述，跑真引擎数命中条数 |
| **② 边际召回** | 从词典删掉它，评测集里有多少**正例**由 hit 变 miss | 逐词删除后全量重跑评测 |
| **③ 规则可达性** | 条款侧"仅靠该词可达"的规则条数（删词后该概念组失去这些规则的入口；个别词可能仍经其他概念组命中，见 §5 勘误） | 统计组内其他词均不在该条款文本、只有它在的规则数 |

**判定表**

| 情形 | 处理 |
|---|---|
| ①大、②=0、③=0 | **直接删**（零代价，无需裁定） |
| ①大、②≠0 或 ③≠0 | **口径裁定**（负责人决定，权衡"规则层召回 vs ②段信噪比"） |
| ①小 | 保留（多为违规专有词：坐支／私存／白头单／侵占／摊派…） |

**收录口诀**：把候选词单独放进一句合法表述，若它会让合规项目被打上命中提示 → 不许收入。
违规形态总带限定词（"占用耕地…"、"未按…程序"），**收限定词，不收被限定的中性动作**。

## 3 2026-11-06 的实测结论与裁定

**已删（零代价）**：
- `造林`（#43）、`种树`（#44）——② = 0 条、③ = 0 条。
- `兑付`（#43，本属中性付款动词）；同组曾试过用上位词 `收益分配` 替代，实测**更差**（合规描述里"收益分配方案经成员会议审议"极常见，新增负对照误报 C145/C150（N1-N3 口径 2 条；按 N4 之后的 22 条负对照重算为 3 条，含专为此设的 C161）），故未采用。

**暂不动（负责人口径裁定：选 A 方案）**：

| 词 | ① 误报面 | ② 边际召回 | ③ 仅靠该词可达 | 备注 |
|---|---|---|---|---|
| 绿化 | 62 | 1（C21） | 9 | C21 期望提示是**转包分包**，此命中为错误维度 |
| 挖塘 | 62 | 0 | 11 | 删它规则覆盖损失最大 |
| 苗木 | 62 | 1（C80） | 3 | C80 期望提示是**变更程序**，此命中亦为错误维度 |
| 草皮 | 62 | 0 | 6 | |
| 景观 | 62 | 0 | 4 | |

- 删这五个 → 规则侧失去 **33 条**"仅靠该词可达"的覆盖；删绿化/景观/草皮 → 失去 **19 条**。
- **裁定：暂不删。** 理由：②段是"提示非判定"，而这些词是条款侧出现频次很高的违规动作词；
  在**没有"LLM 蕴含复核层"接入、也没有实测②段信噪比**之前，删词等于用规则召回能力赌精度。
- **重评触发条件**：LLM 蕴含复核接入、且 ②段在真实体检案例上测出信噪比之后，按同一三判据重算再定。

## 4 配套的合规负对照（数据仓）

边界靠负对照钉死，不靠注释约定。当前四个批次：

| 批次 | 案例 | 钉住的边界 |
|---|---|---|
| N1 | C140-C147（8 条） | 八类合规申报情形基线 |
| N2 | C148-C157（10 条） | 程序性禁止维度（招投标/资金存放/票据/资产/重复申报/摊派） |
| N3 | C158 荒山造林／C159 按期兑付工程款 | 合法项目内容词、中性付款动词 |
| N4 | C160 荒山种树／C161 收益分配方案合规 | 再删「种树」后的边界；并防「收益分配」类上位词被加回 |

纪律（N1 起沿用）：**禁否定式**（"不存在违规"会与词表共现误报）、**避开高权重触发词**（补助/补贴/福利/奖金）、
150-300 字、要件可溯源、复核人签字后才算生效。扩词/收词 PR 必须附对应批次的负对照实测 0 误报证据。

## 5 勘误记录

2026-11-06 首版代价表把「③ 仅靠该词可达」的挖塘、绿化两格算小了（9/7 → 实际 **11/9**）：
初算时「种树」仍在词表内，凡"挖塘＋种树"、"绿化＋种树"共现的条款被"其他组内词均不在条款"条件重复扣减。
删「种树」后这些条款只能靠挖塘/绿化命中。影响面仅限"删词代价估计"（B 实为 33 条而非 29、C 实为 19 条而非 17），
方向上偏保守，不改变"只删种树"的结论。
