## 二、修复清单

1. **「回到典型案例」按钮报错**：`presets` 区缺 `id`，`app.js` 的 `getElementById("presets")` 返回 null 抛 TypeError（提示消失但不滚动）——补 id 修复；
2. **移动端主按钮被遮**：375 宽首屏「开始体检」被固定免责声明栏压住——压缩移动端表单/免责声明高度，主按钮完整可见；
3. **滚动遮挡**：报告标题被吸顶头部盖住——加 `scroll-margin-top`；
4. **焦点管理**：报告生成后焦点移交报告标题（键盘/读屏跟随），移除整篇报告上不可靠的 `aria-live`；
5. **对比度 WCAG AA**：`--ink-faint/--amber/--ash` 加深一档，最差处 3.7:1 → ≥4.84:1（机械检测器 low-contrast 3 条 + tiny-text 1 条全部清零）。

## 三、新增能力

1. **体检过程演示动画**：四步指示（解析描述 → 扫描语料库 → 负面清单比对 → 汇总结果）+ 进度条 + 百分比 + 分步文字；**诚实标注保留**（「演示流程示意 · 静态预置输出，非真实推理」）；
2. **报告四段切换视图**：标签条（带各段计数）取代长滚动，点哪个看哪段；键盘方向键可切换；打印时自动输出全部四段；
3. **随机生成项目描述**：从典型案例随机抽取填入（连续点击不重复）；
4. **未命中体验**：自写描述同样走完整体检动画，落「未在演示语料库中识别到相关政策」提示——说明是演示语料覆盖限制，**不代表项目本身有问题**；
5. **分层折叠**：数据来源说明、报告行政信息、命中依据（文号/条款原文/来源）默认收起，一击展开——证据链完整保留；
6. **微动效**：标签计数滚动、命中条目依次入场；标题印章字模与 favicon（朱砂印章 SVG）。

## 四、质量验证

- 双端（1280 / 375）全流程实测：案例 → 动画 → 报告 → 标签切换 → 折叠展开 → 未命中提示；
- 机械检测器复扫：7 条发现 → 3 条（余 3 条为「红头文件」风格语言：米纸底/纸纹/红头顶线，属设计语言，有意保留）；

- `prefers-reduced-motion` 用户跳过全部动画直达结果。
